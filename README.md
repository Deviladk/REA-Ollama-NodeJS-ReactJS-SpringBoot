# REA – Real-world Execution Agent

REA is a personal AI assistant project designed to interact with the local system and perform real-world tasks using Large Language Models (LLMs).

The project currently uses **Ollama and Node.js** to understand user instructions and execute supported operations through AI-powered tools.

## 🚀 Current Features

- **File Access:** Access and read files from the local system.
- **File Modification:** Modify existing files through AI tool calls.
- **Model Switching:** Change the active Ollama LLM model using natural language commands.

## 🛠️ Technology Stack

- Node.js
- Ollama
- Large Language Models (LLMs)
- JavaScript

## 🔮 Planned Features

The project is under active development. Upcoming features include:

- **React.js UI:** Build a ChatGPT-like conversational interface.
- **Terminal Access:** Execute terminal commands through the AI assistant.
- **Contextual Conversations:** Maintain conversation context across multiple interactions.
- **Global User Context:** Store persistent user information such as name, age, and preferences.
- **Spring Boot REST API:** Build backend REST APIs.
- **Authentication & Authorization:** Implement secure user authentication and access control using Spring Security.

## 🎯 Project Goal

The ultimate goal of REA is to build an intelligent personal AI assistant that can understand natural language, maintain context, interact with the local system, and perform useful real-world tasks.
